## Échecs / apprentissages

- La route `/session/creer/` annoncée par le ticket n'existait pas : elle a été
  ajoutée avec la page initiale, seule à afficher le QR code.
- Le ticket interdit les migrations : seule une migration de métadonnées
  (`AlterModelOptions` et `AlterField`) a été générée pour les libellés, sans
  aucune opération SQL ni changement de table.
- La première capture a échoué car le compte de démonstration n'était pas
  `is_staff` ; la correction du compte a permis de reproduire le parcours réel
  de l'admin.
- Le serveur `runserver --noreload` garde le chargeur de templates en cache :
  il faut le redémarrer après une modification de template pour recapturer.
